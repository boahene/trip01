BUDDY TRIP CALCULATOR
=====================
This is an offline-first Android-friendly trip calculator.

Fastest way to use:
1. Open index.html in Chrome.
2. On Android, use Chrome's menu > Add to Home screen if offered.
3. Enter today's petrol price and your trip details.
4. Save your settings.

For a true APK, open the included Android project in Android Studio and build/install it.
The calculation engine is contained in index.html so it is easy to update later.
